## PicoDrive 3D (Sega Master System / Mega Drive) core - Fork Of The Original PicoDrive

This is a fork of bubble2k16 PicoDrive emulator port for the old 3DS and old 2DS. Currently supports Sega Master System and Mega Drive games only playable in full Ajustable 3D Support, If you want Sega CD and 32X support, Retroarch is your best bet for now.

I tested this only on my Old3ds and everything runs just fine ! Very Experimental build made this afternoon with the help of Claude Code

Hope you guys like it !
