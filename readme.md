
## PicoDrive 3D (Sega Master System / Mega Drive) core - Fork Of The Original PicoDrive

This is a fork of bubble2k16 PicoDrive emulator port forthe old 3DS and old 2DS. Currently supports Sega Master System and Mega Drive games only playable in full Ajustable 3D Support, If you want Sega CD and 32X support, Retroarch is your best bet for now.
